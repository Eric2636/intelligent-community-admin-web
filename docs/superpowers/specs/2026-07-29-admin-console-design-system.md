# 智慧社区后台管理系统统一设计规范

## 目标

将现有后台统一为参照 TDesign Pro 的企业管理后台：克制、清晰、中等偏高信息密度，并强调操作安全、错误可见和审计可追踪。

## 视觉原则

- 主色使用 `#0052d9`，成功、警告、错误分别使用绿色、橙色和红色。
- 页面背景使用浅灰，业务内容使用白色卡片；主要通过边框和背景分层，减少厚重阴影。
- 控件默认高度 32px，重要主操作可使用 40px。
- 圆角控制在 4px 至 6px，保持企业后台的克制感。
- 页面内容使用统一的 24px 外边距和 16px 区块间距。

## 页面结构

每个后台页面按以下顺序组织：

1. 顶部全局栏：环境图标、管理员账号；不重复显示当前页面名称。
2. 页面标题区：面包屑、标题、业务说明、主操作。
3. 筛选区域：固定标签、统一栅格、常用条件和更多筛选。
4. 表格工具栏：结果数量、刷新状态、导出和批量操作。
5. 数据表格：固定操作列、长文本省略、统一状态标签。
6. 详情抽屉或编辑弹窗。

## 全局框架

- 顶部栏固定为 56px 白色栏，页面滚动时保持可见。
- 左侧导航固定为视口高度；菜单区域独立滚动，“收起菜单”固定在底部。
- 环境标识放在管理员账号附近，不单独占用顶部左侧空间。
- 本地和测试环境使用图标提示，鼠标悬浮分别显示“本地开发环境”和“测试环境”；生产环境默认不显示环境标识。
- 当前页面名称只在页面标题区出现一次；顶部栏通过无障碍标签保留页面上下文。

## 筛选规范

- 不使用只有占位文字的无标签筛选项。
- 只有一个搜索条件的页面使用紧凑工具栏，不使用大面积筛选卡片。
- 查询是唯一主按钮，重置使用次按钮；导出不放在筛选按钮组中。
- 文本输入按回车查询，选择条件不自动查询，避免连续请求和结果跳动。
- 常用条件默认展示，低频条件放入“更多筛选”。
- 接口监控默认展示接口、方法、状态、调用时间；IP、操作者、耗时放入更多筛选。
- HTTP 状态类别与精确状态码合并为一个状态筛选入口。
- 请求耗时使用预设区间，自定义区间只在选择“自定义”后展示。

## 表格与异步状态规范

- 工具栏显示结果数量和最近刷新时间。
- 按业务优先级分配列宽，长文本不得挤压状态、时间和操作列。
- 空字段统一显示 `—`，长文本单行省略并通过悬浮提示查看完整内容。
- 长列表在页面滚动时保持表头可见；需要横向滚动时固定关键列和操作列。
- 加载失败时明确提示，并提供重新加载，不将旧数据伪装成最新结果。
- 无数据区分“暂无数据”和“当前筛选无结果”。
- 操作列固定在右侧，查看和编辑使用文字操作，删除使用危险色。
- 状态术语按业务对象统一：
  - 用户账号：正常／冻结
  - 内容：已上架／已下架
  - 模块入口：显示／隐藏
  - 市场分类：启用／停用
  - 接口日志：记录／不记录

## 详情与操作规范

- 列表查看详情优先使用右侧抽屉，复杂编辑使用独立页面或宽弹窗。
- 操作结果包含业务对象，不使用笼统的“操作成功”。
- 状态列只负责展示；冻结、解冻、停用、删除、置顶等操作使用含义明确的文字按钮。
- 重要开关失败后必须恢复原状态。
- 删除、冻结、批量修改等高影响操作需要说明影响范围并二次确认。
- 权限不足的关键操作保留禁用状态，并说明所需权限。

## 日志模块

接口监控详情展示调用时间、来源、方法、完整请求地址、IP、操作者、HTTP 状态、业务码、耗时、请求参数、响应摘要、错误信息和请求编号。

操作审计优先展示中文摘要、业务模块、业务对象、修改前后数据、请求地址、参数、时间、IP 和执行结果。原始 JSON 仅作为折叠的高级信息。

## 本轮范围

- 后台管理前端的整体框架和公共样式。
- 所有现有后台页面的标题、说明、筛选区、工具栏、表格和分页层级。
- 用户管理、管理员管理、小程序模块开关、市场分类、系统通知、接口日志设置。
- 日志中心的操作审计、接口监控、小程序异常上报。
- 模块管理的小区留言、小区市场、业主互助。
- 接口监控和操作审计的详情展示与长字段处理。
- 登录页开发文案清理。
- 操作反馈、空状态和错误状态的一致性改善。

本轮不新增管理首页、不改变后端权限模型，也不部署到测试或生产环境。

## 浏览器验收标准

- 每个现有菜单至少检查首屏、页面滚动、筛选、表格、分页和详情交互。
- 重点检查 1440×900 和 1920×1080 两种桌面尺寸；较窄桌面允许表格横向滚动，但不得遮挡固定操作列。
- 顶部栏始终保持 56px，侧栏高度始终等于视口高度，侧栏底部操作不得随正文滚动。
- 单条件搜索区保持紧凑；多条件筛选不得出现无意义的大块留白。
- 危险操作必须有明确名称、危险色、影响说明和二次确认。
- 页面必须覆盖加载中、空数据、筛选无结果、接口失败和无权限状态。
- 每个模块完成后使用浏览器实际截图复验；没有截图和交互验证的页面不判定为完成。

## 2026-07-29 本地实施结果

- 顶部环境文字已改为账号左侧图标，本地、测试和生产环境遵循差异化展示规则。
- 用户与管理员页面使用紧凑搜索；内容管理、接口日志设置、操作审计和异常上报使用带固定标签的筛选面板。
- 内容列表已将上架、置顶状态与操作分离；管理员多操作列使用带悬浮说明的图标按钮。
- 接口监控按微信小程序和后台管理分为两个页签，列表突出完整请求地址、HTTP 状态和耗时，详细参数进入右侧抽屉。
- 操作审计列表补充业务模块、业务对象和执行结果，详情展示请求地址、请求参数及修改前后数据。
- 核心列表加载失败时清空旧结果，并显示错误提示和重新加载入口；空数据与筛选无结果使用不同文案。
- 已在本地浏览器逐页打开现有菜单，并复验用户管理、管理员管理、操作审计、接口监控和内容管理的首屏与长列表滚动。
