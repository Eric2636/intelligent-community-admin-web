# 后台可读用户身份展示设计

## 目标

后台运营界面不再直接展示小程序用户 ID；所有业务关联、权限校验和审计仍使用 ID。

## 范围

- 管理员绑定弹窗和管理员表格只显示小程序昵称。
- 小程序异常上报列表、详情和关键词查询使用用户昵称；无法关联时显示“匿名用户”或“用户已删除”。
- 接口监控将“用户/管理员 ID”筛选改为可读身份关键字，匹配小程序昵称、管理员账号以及保留的内部 ID。
- 内容管理把发布者检索改为昵称；后台发布不再让管理员手输发布者 ID，内容一律使用其已绑定的小程序用户。公告保持管理员可直接发布的规则。

## 非目标

- 不修改数据库结构、历史日志记录或审计字段。
- 不删除 API 中内部 ID 字段；仅避免把它作为运营界面的默认信息展示。
- 不改变用户绑定、内容归属或权限规则。

## 验收

运营人员在上述页面可通过昵称/管理员账号完成日常识别和筛选，不会看到小程序用户 ID；同名昵称不影响内部提交和权限判断。
