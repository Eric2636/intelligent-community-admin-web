# 智慧社区后台管理系统

基于 Vue 3、Vite、TypeScript 和 Ant Design Vue 的智慧社区后台管理前端。

## 开发

```bash
npm install
npm run dev
```

开发环境下，Vite 会把 `/api` 代理到 `http://127.0.0.1:3000`。

## 构建

```bash
npm run build
```

## 后台界面规范

- 后台采用参照 TDesign Pro 的企业管理后台风格：浅灰页面背景、白色业务卡片、`#0052d9` 主色和中等偏高的信息密度。
- 列表页统一使用“页面标题与说明 → 筛选面板 → 表格工具栏 → 数据表格”的结构；主操作位于标题区，刷新与导出位于表格工具栏。
- 接口监控提供微信小程序、后台管理两个来源页签。常用条件为接口、请求方法、响应状态和调用时间；IP、操作者及耗时范围收纳在“更多筛选”。
- 操作审计详情优先展示中文业务摘要，请求地址和原始审计数据作为可展开的辅助信息。
- 用户、管理员和内容列表将“当前状态”与“执行操作”分开；管理员的次级操作使用图标按钮，鼠标悬浮可查看准确含义。
- 核心列表请求失败后会清空旧结果、显示错误原因和“重新加载”入口，不会把历史数据继续显示成最新结果。

本地前端默认地址为 `http://127.0.0.1:5174`。建议重点检查：`/users`、`/feedbacks`、`/contents/posts`、`/api-access-logs`、`/system-logs`、`/api-endpoints`。

## 后台界面本地验收

1. 启动本地后端与后台前端，访问 `http://127.0.0.1:5174/`。
2. 使用 1440×900 和 1920×1080 两种桌面尺寸检查全部菜单。
3. 本地和测试环境通过管理员账号左侧的图标识别，鼠标悬浮可查看环境名称；生产环境不显示该图标。
4. 检查页面标题、筛选标签、空数据、固定表头、固定操作列、横向滚动、分页和详情抽屉。
5. 列表接口失败时必须清空旧结果并显示“重新加载”，恢复服务后可通过该按钮重新获取数据。
6. 删除、冻结、停用、上下架和置顶等高影响操作必须显示明确对象、影响说明和二次确认。

## 键盘操作

- 登录页支持普通 Enter 登录。
- 用户、管理员、内容、系统日志和小程序接口错误日志列表支持普通 Enter 查询；筛选变化与查询都会先回到第 1 页。
- 后台搜索不是热搜索；输入法组合态、keyCode 229 和长按重复键不会触发查询或登录。
- 连续查询采用 latest-wins，较早返回的请求不会覆盖最新结果。

## 意见反馈

- “意见反馈”菜单和 `/feedbacks` 页面允许超级管理员与平台管理员访问。
- 页面以只读卡片列表展示头像、昵称、身份、反馈内容和提交时间，默认按时间倒序分页。
- 支持按昵称/反馈内容关键词、用户身份和提交时间筛选；关键词支持 Enter 查询。
- 当前不提供标题、处理状态、处理备注、修改或删除功能；查询失败会清空旧卡片并显示重新加载入口。

## 系统通知

- “系统通知”菜单和 `/system-notices` 页面只对 `SUPERADMIN` 显示和开放；普通管理员深链访问会被路由守卫拦截，API 仍会再次校验权限。
- 超级管理员填写纯文本标题和内容，发布前需要二次确认。页面使用按管理员隔离的 `clientRequestId` 保存发布意图，重复提交或网络重试不会重复发送。
- 通知发送给发布事务执行时全部已启用的小程序用户；成功后显示实际接收人数，当前阶段不支持撤回。

## Docker 部署

```bash
docker build -t ic-admin-web:latest .
docker run -d --name ic-admin-web --restart unless-stopped -p 8089:80 ic-admin-web:latest
```

容器内 Nginx 会托管前端静态文件，并把 `/api/` 反代到 `ic-admin-api:3000`。
